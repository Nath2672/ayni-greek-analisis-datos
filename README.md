# ayni-greek-analisis-datos
# Ayni Greek Yogurt - Ciencia de Datos

## Descripción del proyecto

Sistema de análisis y predicción de demanda
mediante técnicas de Ciencia de Datos y Machine Learning.

## Objetivo

Analizar las ventas, estudiar la demanda y
apoyar la planificación de producción e inventario.

## Herramientas utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- SQLite
- Jupyter Notebook

## Resultados

- Análisis de ventas.
- Análisis de inventario.
- Predicción de demanda.
- Recomendación de producción.
