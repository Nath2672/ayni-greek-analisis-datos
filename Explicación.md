# Ayni Greek Yogurt - Ciencia de Datos

# Sistema de análisis y predicción de demanda para Ayni Greek Yogurt

**Proyecto de Ciencia de Datos y Machine Learning**

## 1. Descripción del proyecto

Este proyecto consiste en el desarrollo de un sistema de análisis y predicción de demanda para Ayni Greek Yogurt, un emprendimiento dedicado a la elaboración y comercialización de yogur griego en la ciudad de Latacunga, Ecuador. El emprendimiento lo fundamos hace 3 años.

La solución utiliza técnicas de Ciencia de Datos y Machine Learning para analizar información comercial, identificar patrones de ventas, estudiar el comportamiento de la demanda y generar estimaciones que contribuyan a la planificación del inventario y la producción.

El sistema integra herramientas de programación, análisis estadístico, gestión de bases de datos y visualización para transformar los datos en información útil para apoyar la toma de decisiones empresariales.

**Nota:** Para el desarrollo y las pruebas del sistema se utilizaron datos simulados. Por lo tanto, los resultados presentados tienen fines académicos y demostrativos y no representan los resultados históricos reales de la empresa.

## 2. Planteamiento del problema

La planificación de la producción y el inventario constituye un desafío para los emprendimientos dedicados a la elaboración de productos alimenticios.
